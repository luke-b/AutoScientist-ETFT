# 2024-12-10 GAP Analysis

## Gap ID: GAP-0003
- **Requirement ID:** REQ-ROADMAP-2.1
- **Expected outcome:** Build foundational datasets (D_Gen, D_Rationale) necessary to teach the LLM how algorithms evolve under extreme memory constraints. Specifically, milestone 2.1 calls for Data Acquisition & Preprocessing (e.g. ECG dataset) via a standardized data loader accessible to empirical agents.
- **Observed outcome:** There are no data loaders available for TinyML models on healthcare time-series tasks.
- **Evidence:** `strategy_docs/development_roadmap.md` Phase 2, Milestone 2.1.
- **Severity and impact:** HIGH - Blocks the end-to-end TinyML healthcare pipeline.
- **Dependencies:** `datasets` and `scikit-learn`.
- **Proposed remediation:** Create `corpus/healthcare_loader.py` to acquire and preprocess the `mstz/heart_failure` dataset (as an accessible alternative to raw ECG time series).
- **Verification approach:** Unit tests `tests/test_healthcare_loader.py` to assert data types, split shapes, and binary targets.
- **Remaining uncertainty:** None.
