- **Expected Outcome:** ARL targets TinyML-specific literature ("ultra-low-power time series classification", "hardware-aware neural architecture search") by default when searching for improvements for edge models.
- **Observed Outcome:** ARL defaults to generic "deep learning improvement techniques" unless manually overridden, and doesn't aggregate multiple strategic queries for TinyML.
- **Evidence:** `agents/run_arl.py` line 76: `query = query_override if query_override else f"{bottleneck} deep learning improvement techniques"`
- **Severity/Impact:** Medium. Without specific edge queries, the ARL might synthesize generic GPU-heavy improvements that will be rejected by the memory filter, wasting cycles.
- **Proposed Remediation:** Update the ARL entrypoint or literature searcher to support domain-specific query profiles (e.g., a "tinyml" profile) that automatically inject these specific queries.
