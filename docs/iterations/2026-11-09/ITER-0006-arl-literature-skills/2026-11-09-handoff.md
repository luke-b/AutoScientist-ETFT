# Delivery Handoff

**Iteration ID:** ITER-0006-arl-literature-skills
**Date:** 2026-11-09

## Delivered Capability
The Agentic Research Loop (`run_arl.py`) now natively supports dynamic formulation of literature queries tailored to the domain of "TinyML for Global Health" (Milestone 3.2). When launching ARL, users can pass `--domain tinyml` to automatically structure ArXiv queries targeting "ultra-low-power time series classification" and "hardware-aware neural architecture search". This focuses the micro-experiments on relevant literature rather than generic deep learning improvements, which typically fail the strict memory stage-gates.

## Previous Behavior
The ARL hardcoded a single fallback query format: `{bottleneck} deep learning improvement techniques`.

## New Behavior
The CLI now accepts `--domain [DOMAIN]`.
If `--domain tinyml` is passed (and no explicit `--query` is set), the fallback dynamically changes to `{bottleneck} ultra-low-power time series classification hardware-aware neural architecture search`.
Explicit queries passed via `--query` still take precedence over everything.

## Step-by-Step Manual Testing
1. Configure ARL to target a bottleneck, using the tinyml domain:
   `python -m agents.run_arl --bottleneck depthwise_conv --domain tinyml`
2. Ensure you have network connectivity to arXiv (or the cached vector store).
3. Observe the `agents.literature.searcher` logs hitting arXiv with the targeted strings.

## Known Limitations
- The domain queries are currently hardcoded in a standard conditional block inside `run_arl.py`. If we expand to multiple domains in the future, this should be refactored into a configuration file.
