# Execution Plan

**Iteration ID:** ITER-0006-arl-literature-skills
**Date:** 2026-11-09

## 1. Problem Statement and Business Rationale
Milestone 3.2 requires launching the Agentic Research Loop (ARL) targeting "ultra-low-power time series classification" and "hardware-aware neural architecture search". The current ARL defaults to generic "deep learning improvement techniques", which will likely yield architectures that fail the strict 256KB memory threshold. We need to implement and deploy ArXiv queries specifically tailored for TinyML time-series classification techniques.

## 2. Current vs. Target Behavior
- **Current:** `agents.run_arl` uses a single generic query: `{bottleneck} deep learning improvement techniques`. This is hardcoded in the `run_arl` function and as the default help text in `parse_args`.
- **Target:** Allow configuring a `--domain` argument (e.g., `tinyml`) in `run_arl.py` which dynamically reformulates the fallback query. If `--domain tinyml` is given, it should construct `"{bottleneck} ultra-low-power time series classification hardware-aware neural architecture search"`.

## 3. Scope and Non-Goals
- **In-Scope:** Update `agents/run_arl.py` to support domain-specific query formulation. Update the CLI arguments of `run_arl.py` to accept `--domain`. Write tests for the query building logic.
- **Non-Goals:** Running the full ARL end-to-end execution. We only need to configure the literature query generation correctly and test it.

## 4. Implementation Milestones
1. Modify `agents/run_arl.py` CLI `parse_args()` to add an optional `--domain` argument.
2. In `agents/run_arl.py:run_arl()`, add a `domain` parameter (default `None`). If `query_override` is not provided, evaluate `domain`: if `domain == "tinyml"`, set the query to `f"{bottleneck} ultra-low-power time series classification hardware-aware neural architecture search"`. Otherwise, use the existing default `f"{bottleneck} deep learning improvement techniques"`.
3. In `agents/run_arl.py:main()`, pass `args.domain` into `run_arl()`.
4. Replace the contents of `agents/tests/test_run_arl.py` with a patch on `LiteratureSearcher.search` or by mocking components inside `run_arl` to verify that when `domain="tinyml"` is passed in, the correct query string is used without attempting to actually hit ArXiv or run the pipeline.
5. Run the full test suite via `pytest` to ensure no regressions were introduced.
6. Complete pre-commit steps to make sure proper testing, verifications, reviews and reflections are done.
7. Submit the final changes.

## 5. Acceptance Criteria
- **AC1:** `run_arl.py` accepts `--domain tinyml` via CLI.
- **AC2:** When `--domain tinyml` is used, the search query correctly incorporates the terms "ultra-low-power time series classification" and "hardware-aware neural architecture search".
- **AC3:** A mocked test in `agents/tests/test_run_arl.py` validates the correct query string is passed to `search()`.
- **AC4:** Pre-commit steps pass and submission completes.
